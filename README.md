# Tehfiz

The website and web apps at [tehfiz.com](https://tehfiz.com): tools for Quran teachers to record recitation mistakes word by word on the mushaf, and for students to review that feedback.

## What is in this repository

| Path | What it is |
|---|---|
| `index.html` | The landing page |
| `dhor/` | The dhor (listening) service page |
| `privacy/` | Privacy and terms |
| `app/teacher/` | The teacher app |
| `app/student/` | The student viewer |
| `app/shared/` | Code, styles and icons used by both apps |

The apps are plain HTML, CSS and JavaScript with no build step. The API they talk to is kept in a separate, private repository.

## Privacy

Student names are never stored on Tehfiz's servers. See [tehfiz.com/privacy](https://tehfiz.com/privacy/).
